Showpass - Premium Movie Ticket Booking System
Showpass is a premium, modern movie ticket booking web application built with Django and Python. It features a sleek, dark-themed UI styled with Glassmorphism and Bootstrap 5 to deliver an immersive user experience.

Users can seamlessly browse trending movies, watch YouTube trailers, select specific seats via an interactive grid, and checkout through a fully simulated Razorpay mock payment gateway. Upon successful payment, users receive a downloadable PDF ticket with an embedded QR code, processed securely in the background via Celery.

For administrators, Showpass includes a highly customized, robust Django-Jazzmin admin dashboard. It provides powerful real-time analytics on sales, occupancy rates, and user growth, along with complete control over theater management, movie listings, and showtimes.

Showpass is the perfect blend of a beautiful frontend user experience and a powerful, data-driven backend management system.
